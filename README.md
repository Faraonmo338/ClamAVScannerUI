# ClamAV GUI Scanner (Windows 11 Style)

Cтильная и легкая графическая оболочка (GUI) для антивирусного консольного движка **ClamAV** на Windows. 

Написана на Python с использованием библиотеки `CustomTkinter`. Позволяет быстро проверять отдельные файлы и целые директории без необходимости работы через командную строку.

## Основные возможности

* **Дизайн в стиле Windows 11**: Полноценная темная тема (Dark Mode), скругленные элементы и чистый интерфейс.
* **Асинхронность (Multi-threading)**: Процесс сканирования вынесен в отдельный поток — окно программы не зависает и свободно перемещается во время проверки.
* **Цветовая индикация логов**: Вывод результатов в реальном времени. Чистые файлы подсвечиваются зеленым, обнаруженные угрозы — ярким красным, а системные статусы — желтым.
* **Без всплывающих консолей**: Фоновые утилиты `freshclam.exe` и `clamscan.exe` запускаются в скрытом режиме без лишних окон CMD.
* **Автообновление баз**: Перед каждой проверкой скрипт автоматически подтягивает свежие сигнатуры.

## Стек технологий

* **Python 3.x**
* **CustomTkinter** — GUI фреймворк
* **Subprocess & Threading** — фоновая работа с движком ClamAV
* **ClamAV for Windows** — антивирусный движок
